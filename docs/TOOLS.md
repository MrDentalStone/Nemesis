# Nemesis MCP tools

Generated by `go run ./cmd/gendocs` from the server's own tool list; do not edit by hand.

Nemesis is a stdio MCP server. Every tool returns plain text written for the AI to read. Tools that act on the table go through the Nemesis pad in Tabletop Simulator, which refuses anything outside the AI's own seat, and every action is refused while the pad's STOP button is on.

## Reading the table

### `table_state`

Everything public about the Commander table: each seat's player, life, commander damage taken, hand COUNT, library COUNT, graveyard/exile/command zone cards, and battlefield (name, tapped, face-down, land row, counter tiles resting on the card, and the on-card state players set with right-click: +1/+1 counters, loyalty, keywords, notes, phased out, token). Your own seat is flagged. Opponents' hands and all libraries are never listed - that is by design.

No parameters.

### `my_hand`

Your own hand (and companion/secondary hand zone) with full card text. Only your seat is ever readable.

No parameters.

### `wait_for_event`

Block until something happens at the table, then return every event so far, one line each: [chat], [play] (another player cast or played a card, with its text and whether you could respond), [round] (your ask_table settled), [turn], [button] (admin pad: your_turn/undo/stop/resume/yes/no; player pads), [zone] (your cards moved), [log] (life and commander damage lines), [mode], [new_player], [seat], [import]. Use this during other players' turns instead of polling.

| Parameter | Type | Description |
|---|---|---|
| `timeout_seconds` | integer | seconds to wait for the first event (default 45, max 600; stay under your client's tool-call limit). Nothing is lost between calls. |

### `parse_card`

Parse a TTS card nickname/description into name, type, mana, oracle text and P/T (the importer's name, type line and mana value format, or a plain name).

| Parameter | Type | Description |
|---|---|---|
| `nick` (required) | string | the card's TTS nickname as shown by table_state |
| `desc` | string | its TTS description, if you have it |

### `tts_log`

Recent print/error output captured from Tabletop Simulator's Lua. Check this when a tool misbehaves.

| Parameter | Type | Description |
|---|---|---|
| `n` | integer | how many recent lines (default 50) |

## Talking to the table

### `say`

Speak in TTS chat as yourself. Announce intent BEFORE acting, answer questions, call out life changes.

| Parameter | Type | Description |
|---|---|---|
| `text` (required) | string | what to say in table chat, as yourself, the player |
| `loud` | boolean | also flash it on everyone's screen (use for attacks, big plays, questions) |

### `ask_table`

Ask the table loudly and WAIT for the answer: one per seat, from chat ('no', 'go' pass; 'wait', 'hold' respond; 'yes'/'no'), a card dropped on your board, or optional player pads. Silence for the wait settles it. Returns all_no (go on), respond by <colour> (stop, let them act; it names the card if they dropped one), or answered/timeout with answers like 'Blue=yes, White=no'. For your own spells use cast, which has its own quiet window; ask only for triggers and real questions.

| Parameter | Type | Description |
|---|---|---|
| `text` (required) | string | the question, e.g. 'Casting Craterhoof Behemoth, any responses?' or 'Want me to apply agreed damage to your tracker?' |
| `kind` | string | responses (default) or yesno |
| `seats` | null or array | colours to ask (default: every seated human) |
| `wait` | null or integer | seconds of silence that settle it (default: the pad's setting, 15; 0 waits for every answer) |

### `cancel_round`

Close the open ask_table round without a result (the question no longer matters, or players answered in chat).

No parameters.

### `player_pads`

Optional: place a small Yes / No / Respond pad above each seated human's mat, or remove them all. Chat answers work without them; only on request.

| Parameter | Type | Description |
|---|---|---|
| `remove` | boolean | true removes every player pad instead |

### `claim_seat`

Ask to sit at a colour. A human must press Yes on the pad before it takes effect; wait_for_event reports the 'seat' event.

| Parameter | Type | Description |
|---|---|---|
| `color` (required) | string | a seat colour the table has (White, Red, Yellow, Green, Blue, Purple...) - must be unseated |

## Playbook, modes and decks

### `playbook`

How to play at this table: hard rules, game flow, your turn, other players' turns, tool habits. Read it before the first game if your client did not already load PLAYBOOK.md; part=rules gives the Commander rules guide.

| Parameter | Type | Description |
|---|---|---|
| `part` | string | playbook (default: how to play at this table) \| rules (the Commander rules guide and its opponent-turn checklists) \| all |

### `list_modes`

The play modes this table offers (modes/*.md), with the current one marked. The admin pad cycles through them; mode_rules gives one mode's rules.

No parameters.

### `mode_rules`

The rules for a play mode: who to target, when knockouts are allowed, what to remove, what deck to bring, plus the new-player rules that apply in every mode. Read it before choosing a deck and whenever ev=mode reports a change.

| Parameter | Type | Description |
|---|---|---|
| `mode` | string | mode id or name (default: the mode set on the pad) |

### `list_decks`

Tested 100-card decks (decks/*.md) with commander, colours, bracket and a one-line summary. Import one with import_deck(deck=<id>).

| Parameter | Type | Description |
|---|---|---|
| `mode` | string | only decks for this mode id; 'all' for every deck (default: the mode set on the pad) |

### `deck_info`

A deck's pilot notes (mulligans, game plan, key synergies, what to hold back per mode) and its full list. Read it after importing so you know how to play the deck.

| Parameter | Type | Description |
|---|---|---|
| `deck` (required) | string | deck id from list_decks |

### `import_deck`

Build a deck with the table's deck importer, place it in your library and command zone, and deal your opening 7 (waits ~5-20 s for the piles). Then decide keep or mulligan; deck_info has the pilot notes.

| Parameter | Type | Description |
|---|---|---|
| `data` | string | or: a decklist (a 'Commander' header line for the commander, 'Deck' for the 99) or an Archidekt/Moxfield/Scryfall deck URL |
| `deck` | string | a deck id from list_decks (preferred) |

## Your cards

### `begin_turn`

Start your turn in one call: untap everything, draw 1 (unless skip_draw), then return your hand and the whole table. Say your upkeep triggers yourself.

| Parameter | Type | Description |
|---|---|---|
| `skip_draw` | boolean | skip the draw (the first player's first turn in a 2-player game) |

### `cast`

Cast a spell in one call: tap the mana, announce it, put it on the stack, give the table a quiet window to respond (they drop a card on your board or say 'wait'), then resolve it onto your battlefield or into the graveyard. Returns 'resolved' (carry out its effect now if it has one) or the response, with the spell left on the stack for you to finish. Lands use play.

| Parameter | Type | Description |
|---|---|---|
| `guid` (required) | string | the spell: a card in your hand or command zone |
| `note` | string | targets or modes, e.g. 'targeting White's Arahbo' |
| `tap` | null or array | your mana sources to tap for it |
| `to` | string | where it goes when it resolves: creature \| other \| graveyard (default: by type, instants and sorceries to the graveyard) |
| `window` | null or integer | leave out: the server holds Game Changers, mana value 4+, spells that affect other players and your commander for 8 s, and resolves the rest at once |

### `draw`

Draw n cards for a card effect. Not for your turn's draw (begin_turn does it) or your opening hand (import_deck deals it). Returns the hand.

| Parameter | Type | Description |
|---|---|---|
| `n` | integer | cards to draw (default 1) |
| `reason` | string | the card or rule that makes you draw, e.g. 'Ponder' (needed after begin_turn, which already drew for the turn) |

### `mulligan`

Return your hand to the library, shuffle, draw 7. Then bottom cards with move(to=library_bottom).

No parameters.

### `shuffle_library`

Shuffle your library (forgets anything look saw).

No parameters.

### `play`

Put a card from your hand or command zone onto your battlefield (land/creature/other row) or onto the stack spot. Say what you're doing first.

| Parameter | Type | Description |
|---|---|---|
| `guid` (required) | string | card guid from my_hand or table_state (command zone) |
| `row` | string | land \| creature \| other \| stack (default other). Use stack for instants/sorceries and anything that should be announced before it resolves. |

### `tap`

Tap permanents on your battlefield (mana, attackers, abilities).

| Parameter | Type | Description |
|---|---|---|
| `guids` (required) | null or array | guids of permanents on your battlefield |

### `untap`

Untap your permanents - specific guids, or all=true for the untap step.

| Parameter | Type | Description |
|---|---|---|
| `all` | boolean | untap everything on your battlefield (untap step) |
| `guids` | null or array | specific permanents to untap |

### `flip`

Flip one of your cards (transform DFCs, morph face-up, etc.).

| Parameter | Type | Description |
|---|---|---|
| `guid` (required) | string |  |

### `move`

Move one of your objects between zones: resolve a spell from the stack to the graveyard/battlefield, discard, exile, return to hand, put on top/bottom of library, commander back to the command zone.

| Parameter | Type | Description |
|---|---|---|
| `guid` (required) | string | one of your objects (hand, battlefield, graveyard, exile, command zone, or a library card from look) |
| `to` (required) | string | graveyard \| exile \| command \| hand \| stack \| battlefield \| library_top \| library_bottom |
| `row` | string | when to=battlefield: land \| creature \| other |

### `attack`

Declare attackers: taps them, announces the attack loudly and waits for the defender's blocks in chat (silence = no blocks). Returns what they said; then work out damage, say the numbers and let them move their tracker.

| Parameter | Type | Description |
|---|---|---|
| `guids` (required) | null or array | attacking creatures (your battlefield) |
| `target` (required) | string | defending colour, or a planeswalker/battle name |
| `note` | string | anything extra to announce (triggers, pump, etc.) |
| `wait` | null or integer | seconds to wait for the defender to declare blocks (default 20) |

### `end_turn`

Pass the turn to the next player (TTS turn marker), after your end step. If it fails, the turn was NOT passed: say so, never claim you passed.

| Parameter | Type | Description |
|---|---|---|
| `force` | boolean | only when a human says the marker is stuck on you |

## Library effects

### `look`

Look at the top n cards of your OWN library (scry, surveil, 'look at the top card'). The cards are taken off the top into your hidden secondary hand zone; put them back with move(to=library_top) in the order you want (last moved = top) or move(to=library_bottom), or keep them where the effect allows. Only use when a card effect allows it, and say so.

| Parameter | Type | Description |
|---|---|---|
| `n` | integer | how many cards from the top (default 1) |

### `search_library`

Search your OWN library for cards matching a query (tutors, ramp like Cultivate/Wood Elves/Skyshroud Claim) and put them onto the battlefield or into hand, then shuffle. Reports only the cards taken and the number of matches. Only when a card effect allows it; say which card.

| Parameter | Type | Description |
|---|---|---|
| `query` (required) | string | case-insensitive text matched against card name and type line, e.g. 'forest', 'basic land', 'Eternal Witness' |
| `desc` | boolean | also match the oracle text |
| `n` | integer | how many matching cards to take (default 1) |
| `no_shuffle` | boolean | skip the shuffle afterwards (almost never) |
| `row` | string | battlefield row: land, creature, other (default other) |
| `tapped` | boolean | put onto the battlefield tapped |
| `to` | string | battlefield (default) or hand |

### `reveal_until`

Reveal cards from the top of your library until one matches the query (cascade, 'reveal until a creature', Gnawbone-style effects). The revealed cards are laid face-up on the stack row and listed; then move() them as the effect says (cast the hit, library_bottom the rest, etc.). Only when a card effect allows it; say which.

| Parameter | Type | Description |
|---|---|---|
| `query` (required) | string | text matched against name and type line of each revealed card, e.g. 'creature', 'land', 'instant' |
| `max` | integer | stop after this many cards (default 20) |
| `max_cmc` | integer | cascade: only a card with mana value LESS than this counts as the hit |

### `reveal`

Reveal cards (from hand, library via look, etc.) to the whole table: announced in chat and laid face-up on the stack spot. Move them back afterwards.

| Parameter | Type | Description |
|---|---|---|
| `guids` (required) | null or array | guids of permanents on your battlefield |

## Counters, tokens and life

### `mark`

Set ON-CARD state on one of your cards the way the table's right-click menu does: +1/+1 counters, generic counters, loyalty, P/T tweaks, keyword icons, a notepad note, phased out, token marker. Prefer this over counter tiles; table_state shows it as 'on-card:'. Deltas add to the current value.

| Parameter | Type | Description |
|---|---|---|
| `guid` (required) | string | one of your cards on the battlefield |
| `counters` | integer | delta of generic named counters (charge, oil, time...) |
| `keywords` | null or array | keyword icons to add: flying, first strike, double strike, deathtouch, lifelink, trample, vigilance, menace, reach, haste, hexproof, indestructible, defender, frozen, monstrous, stun, exert, renowned, suspend |
| `loyalty` | integer | delta of loyalty on a planeswalker |
| `note` | null or string | set the card's notepad text (empty string clears) |
| `phased` | null or boolean | true = phased out marker on, false = off |
| `plus_one` | integer | delta of +1/+1 counters (negative removes; -1/-1 counters are negative +1/+1 here) |
| `power` | integer | delta to power (non-counter effects you want shown) |
| `remove_keywords` | boolean | remove the listed keywords instead of adding them |
| `token` | null or boolean | true = mark as a token |
| `toughness` | integer | delta to toughness |

### `counter`

Drop counters/keyword tokens from the table's bags onto one of your permanents. A +X/+Y tile can be set to a value with p/t (one tile reading +3/+3 is how the table tracks three counters).

| Parameter | Type | Description |
|---|---|---|
| `guid` (required) | string | one of your permanents |
| `kind` | string | bag name on the table: '+X/+Y Counter' (default), 'Counter', 'Poison Counter', 'Loyalty Counter', 'Flying', 'Deathtouch', 'Lifelink', 'Haste', 'Monstrous', ... (keyword bags stick a keyword on the card) |
| `n` | integer | how many (default 1) |
| `p` | null or integer | for a +X/+Y tile: the power value to show (e.g. 3 for +3/+3, or 13 to label a 13/13 Hydra) |
| `t` | null or integer | for a +X/+Y tile: the toughness value to show |

### `spawn_token`

Create token cards on your battlefield: found on Scryfall, built by the deck importer.

| Parameter | Type | Description |
|---|---|---|
| `query` (required) | string | Scryfall SEARCH SYNTAX for the token (t:token is added for you). Use an EXACT name with ! plus -is:dfc so a double-faced or similarly named token is not picked: '!Treasure -is:dfc', '!Food -is:dfc', '!Beast pow=3 tou=3 c:g -is:dfc', '!Plant pow=0 tou=1 -is:dfc'. Plain words like 'Beast 3/3' do not work. |
| `n` | integer | how many copies (default 1) |
| `row` | string | creature \| other (default creature) |

### `adjust_life`

Change any player's life total on their tracker (damage you deal, life you gain or lose). Announced in chat automatically. Only after the table agrees on the damage.

| Parameter | Type | Description |
|---|---|---|
| `color` (required) | string | whose life total: a seat colour (White, Red, Yellow, Green, Blue, Purple...) |
| `delta` (required) | integer | change, negative for damage/loss |

### `reset_life`

Set a seat's life tracker for a new game (default 40). Ask before touching a human's tracker.

| Parameter | Type | Description |
|---|---|---|
| `color` (required) | string | a seat colour (White, Red, Yellow, Green, Blue, Purple...) |
| `value` | integer | new life total (default 40) |

### `commander_damage`

Record commander damage on the table's trackers (21 total from one commander = dead). The table deducts it from the victim's life automatically (cmdrDamageAutoLife), so do NOT also adjust_life for the same damage; the reply says lifeAutoDeducted.

| Parameter | Type | Description |
|---|---|---|
| `delta` (required) | integer |  |
| `from` (required) | string | colour whose commander dealt the damage |
| `to` (required) | string | colour that took it |

## Setting up and between games

### `setup_pad`

Get your pad onto the table. No pad: puts a small Yes/No tile in the middle and asks the table in chat; the pad appears when someone says yes ([pad] event). An outdated pad: updates its script in place, keeping seat and settings. A current pad: reports its version.

No parameters.

### `reset_board`

NEW GAME: destroy all of your cards, tokens and counter tiles in your zones and hands, set your life to 40 and zero the commander damage you have taken (via the table's own reset). Then import_deck. Never touches a human's area.

No parameters.
